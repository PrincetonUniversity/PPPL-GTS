# Example: stochastic edge from magnetic perturbations (random phases)

This case is the same as `../POP2022_UniformPhase`, except that the 8 MP harmonics have different phases:
```
gagf0=6.2,1.5,0.2,3.4,2.8,4.3,5.5,1.9      ! uniform-phase case: gagf0=8*3.14
```

`../POP2022_UniformPhase/README.md` describes the following:
- the setup
- how to run the case
- how to switch off the Poisson solve
- the outputs
